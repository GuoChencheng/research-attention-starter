# Research Attention Starter: assistant instructions

Read CONTEXT.md first. Select one exact task and read its ACTIVE_CONTEXT.md and WORKING_NOTE.md. Do not preload all history.

- Answer explanatory questions directly; create a task only when persistent work is needed. Related material does not imply permission to resume an old task.
- Work on the current bottleneck. Load relevant Wiki passages, sources, methods, or code only as needed.
- Local task files hold the working state. Mark external and model-generated material external_unverified until checked.
- Preserve assumptions, evidence sources, failures, counterexamples, competing explanations, and the next decision. Missing inputs block only dependent steps.
- Distinguish conjectural, conditional, exact_finite, numerical, proved, refuted, and open results. Finite checks do not establish an infinite-size claim. State the assumptions and scope of any proof.
- Humans decide material priority changes, frozen definitions, formal claim promotion, external publication, and expanded AI authority. Do not repeatedly request already valid authorization.
- Default to human-governed work. This starter does not authorize autonomous loops, agent dispatch, cloud jobs, or external writes.
- Update the working note after meaningful progress and run refresh. ACTIVE_CONTEXT.md is a generated view, not a separate authority.
- Before close, check the stated completion criteria, retain useful failures, and write a reusable summary. Do not mark unfinished requested work complete.
- Follow WORKFLOW.md when preserving exact artifacts. File integrity and successful execution do not prove scientific truth.

These are working instructions, not executable access controls. Follow the user's valid instructions and the host assistant's higher-priority rules.
