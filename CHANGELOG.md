# Changelog

## 0.1.0 - 2026-10-04

- Publish the standalone English research workflow, templates, and worked example.
- Provide init, new, refresh, close, and self-test commands using only the Python standard library.
- Use explicit UTF-8 file I/O and preserve the license in generated workspaces.
- Add CI for Linux, macOS, and Windows on Python 3.10 and 3.14.

Scientific certification, autonomous execution, concurrent writers, and full parent-system checkpoint replay are outside this release.
